# Rastreador de Despesas

Projeto desenvolvido durante o Sprint 7 do curso de Desenvolvimento Web da TripleTen.

## Sobre o projeto

O Rastreador de Despesas é uma aplicação web interativa que permite ao usuário controlar um orçamento e acompanhar suas despesas por diferentes categorias.

O projeto foi desenvolvido a partir de um layout previamente criado em HTML e CSS. A principal tarefa deste sprint foi implementar a lógica da aplicação utilizando JavaScript.

## Funcionalidades

- Definir um orçamento.
- Calcular o total das despesas.
- Calcular a despesa média.
- Calcular o saldo disponível.
- Alterar a cor do saldo de acordo com sua situação financeira.
- Calcular o total de despesas por categoria.
- Identificar a categoria com maior volume de despesas.
- Adicionar novas despesas.
- Remover despesas.
- Atualizar automaticamente as estatísticas após alterações.

## Categorias de despesas

O projeto utiliza cinco categorias:

- Mercado
- Comer fora
- Transporte
- Casa
- Assinaturas
